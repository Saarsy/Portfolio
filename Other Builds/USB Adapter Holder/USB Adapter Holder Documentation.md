# What It Is
This adapter holder is a small part of my room’s organization. It contributes to keeping all my USB C to USB A adapters in one place.
# Why I Made it
I Made this because I often lost these small adapters really easily, and I or my family just threw them in some box when we didn’t need them. When we did need them, this small adapter was the only resort we had; nothing could replace it, so I thought that something this important should get its own place to be put.
