# What It Is
This is a print I made to organize, and have a place to put the [Remote Shell](/Remote%20Shell/Remote%20Shell%20Documentation) and another remote in. It has a mounting block on the side so I could attach it directly to my side table.
# Why I Made it
I made this because even after making the [Remote Shell](/Remote%20Shell/Remote%20Shell%20Documentation), it still was thrown around everywhere, it didn't have a proper space to be put still. This print solves that as it has a perfect fit spot for the shell and another remote that is used less.
