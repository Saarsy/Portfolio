# What It Is
This is a countertop protector. It is made from squishy filament called TPU which allows it to sustain hard hits without breaking. It serves as a protector from spinning bar stools or things like foot-opening trash cans, which often slam into the wall, or in my case, the countertop.
# Why I Made it
I made this because day to day I would see things that hit the countertop, which can be chipped really easily. So to have ease of mind, I designed this model, so that even if nothing happens, we don’t have to cringe every time the trash can or stool collides with the countertop.
