# Why I Needed It
This build was essential because this home server that I had, which did so many things, lay on a table where my family worked. If the cables on the server ever got pulled accidentally at the wrong time, the whole thing could get corrupted, so I knew I had to mount this to the wall.
# What It Has
I incorporated many features in my build:
- I had cut out slots in the back to allow for proper cooling while also offsetting the whole back to give it space to breathe
- The holes on the bottom perfectly aligned with the Ethernet cable
- A secure connection from all 3 sides so the server couldn't go anywhere
- Space for the storage wires to pop out
